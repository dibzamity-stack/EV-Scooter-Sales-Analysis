# EV Scooter Sales Analysis Using Excel

## Project Overview

This project focuses on analyzing electric vehicle (EV) scooter sales data using Microsoft Excel.

The analysis involves cleaning raw sales data, creating calculated fields, developing pivot tables, and examining sales performance across different brands, customer segments, sales channels, salespersons, and months.

The objective is to transform raw sales data into meaningful business insights that can support sales performance evaluation and decision-making.

## Objectives

* Clean and prepare raw sales data for analysis
* Analyze sales and units sold
* Evaluate salesperson performance
* Compare sales performance across brands
* Analyze sales by customer segment
* Compare different sales channels
* Identify monthly sales trends
* Present findings using Excel-based analysis

## Dataset

The workbook contains EV scooter sales transaction data, including information about orders, products, customers, sales channels, pricing, discounts, and delivery.

## Data Cleaning

The raw dataset was reviewed and prepared for analysis.

The process included:

* Reviewing missing and inconsistent values
* Cleaning selected fields
* Creating calculated columns
* Preparing the data for pivot-table analysis
* Removing records where applicable

The raw dataset contains 705 records, while the cleaned dataset contains 700 records.
